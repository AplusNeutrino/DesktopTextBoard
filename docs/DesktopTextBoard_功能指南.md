# Desktop Text Board 功能指南

本文档面向 Desktop Text Board 的日常使用者，说明如何启动、编辑、锁定、调整桌面透明文字小组件，以及如何使用网格、合并单元格和分割线等功能。

## 1. 软件定位

Desktop Text Board 是一个 Windows 桌面透明文字板工具。它由两部分组成：

- 桌面小组件：显示在桌面上的透明文字框，只负责展示内容。
- 编辑器窗口：用于编辑文字、设置样式、调整网格和外观。

设计目标是让桌面上保留一块轻量、低干扰的文字区域，同时避免直接在桌面小组件上误编辑、误拖动。

## 2. 启动方式

从 Release 包中解压后，运行：

```text
DesktopTextBoard.exe
```

启动后，程序会常驻系统托盘。可以通过托盘图标打开编辑器。

如果程序无法启动，先确认系统已安装 .NET 8 Windows Desktop Runtime。当前 Release 包是 framework-dependent 版本，不内置 .NET 运行时。

## 3. 托盘菜单

右键托盘图标可打开菜单：

- Open editor：打开编辑器窗口。
- Lock all widgets：锁定所有桌面小组件。
- Unlock all widgets：解锁所有桌面小组件。
- Import backup...：导入备份。
- Export backup...：导出备份。
- Start with Windows：切换是否开机启动。
- Exit：退出程序。

左键点击托盘图标也会打开编辑器。

## 4. 桌面小组件

桌面小组件用于展示编辑器中的内容。它本身不直接编辑文字。

### 锁定状态

每个桌面小组件右上角有锁定按钮：

- 锁定：小组件内容区域不会响应鼠标，降低误触概率。
- 解锁：可以拖动和缩放小组件。

锁定后，小组件不会强制置顶，其他窗口可以盖住它，更接近桌面小部件的行为。

### 移动与缩放

解锁后可以拖动小组件位置，也可以通过边角缩放小组件大小。编辑器中的预览尺寸会随小组件尺寸变化同步。

## 5. 编辑器界面

编辑器主要分三栏：

- 左侧：小组件列表，可以新增、复制、删除小组件。
- 中间：当前小组件的编辑预览区域。
- 右侧：当前小组件的设置面板。

顶部工具栏用于文字格式设置，包括加粗、斜体、下划线、删除线、列表、分割线、对齐、字号、文字颜色、高亮和保存。

## 6. 文字编辑

点击中间预览区域中的某个格子即可编辑该格子的文字。

支持的常用格式：

- 加粗
- 斜体
- 下划线
- 删除线
- 项目符号列表
- 编号列表
- 左对齐、居中、右对齐
- 字号
- 文字颜色
- 高亮颜色

编辑器内容会自动同步到桌面小组件。也可以点击顶部的保存按钮立即保存。

## 7. 分割线

可以通过两种方式插入分割线：

- 点击工具栏的 `— 分割线`。
- 输入 `---` 后按回车。

分割线是轻量文本分割线，会根据所在格子的宽度自动调整长度。

### 分割线对齐

将光标放在分割线所在行，然后点击：

- `左`：分割线左对齐。
- `中`：分割线居中。
- `右`：分割线右对齐。

同一组对齐按钮也用于普通文字段落。

## 8. 小组件模式

右侧设置面板中的 `模式` 支持：

- Single：单块文字板。
- Grid：网格文字板。

如果需要分类、计划表、看板或多栏内容，建议使用 Grid 模式。

## 9. 网格设置

在右侧设置面板的 `高级` 区域可以设置网格。

### 行数与列数

修改：

- 行数
- 列数

然后点击 `应用网格/比例`。

### 行高比例与列宽比例

可以通过比例控制格子的大小。例如：

```text
行高比例：1, 0.7
列宽比例：2, 1, 1
```

含义：

- `1, 0.7` 表示第一行比第二行高。
- `2, 1, 1` 表示第一列比后两列宽。

比例只表示相对大小，不是像素值。

## 10. 直接拖动调整格子大小

点击某个单元格后，它的边界会亮起可拖动把手。

拖动规则：

- 拖内部边界：调整相邻行或列的比例。
- 拖外部边界：调整整个桌面小组件的宽度或高度。
- 单行、单列、单格情况下，也可以拖外部边界改变小组件尺寸。

这种方式适合快速调出“一宽一窄”“一高一低”的布局。

## 11. 合并单元格

合并单元格适合制作类似表格的布局，例如：

- 左侧一个大分类，对应右侧多条内容。
- 上方一个标题区，下方分多列。
- 一对多、多对一的计划表结构。

### 合并步骤

1. 点击第一个单元格。
2. 按住 `Shift`，点击另一个单元格，形成矩形选区。
3. 打开右侧 `高级` 区域。
4. 点击 `合并选区`。

合并时，选区内非空内容会按从左到右、从上到下的顺序合并到新的大单元格中，避免直接丢失内容。

### 拆分步骤

1. 点击一个已合并的单元格。
2. 打开右侧 `高级` 区域。
3. 点击 `拆分单元格`。

拆分后，原内容保留在左上角单元格中，拆出的其他格子为空。

## 12. 外观设置

右侧设置面板提供常用外观选项：

- 背景透明度
- 圆角
- 默认字号
- 显示桌面边框
- 背景颜色
- 边框颜色
- 边框透明度
- 边框粗细
- 内边距
- 默认文字颜色
- 预设外观

如果希望小组件更像桌面贴片，可以降低背景透明度、隐藏边框并适当增加圆角。

## 13. 显示器切换

右侧设置面板中可以选择目标显示器，然后点击 `移动到该显示器`。

适合多显示器场景，例如将计划板固定在副屏桌面区域。

## 14. 数据保存与备份

数据会自动保存到：

```text
%LOCALAPPDATA%\DesktopTextBoard\boards.json
```

建议使用托盘菜单中的导入/导出功能做备份，不建议手动编辑 JSON 文件。

## 15. 常见使用建议

- 日常只看内容时，保持小组件锁定。
- 需要移动、缩放或调整位置时，临时解锁。
- 复杂布局优先使用 Grid 模式。
- 需要表格感时，使用合并单元格，而不是用空格手动排版。
- 分割线用于轻量分组，不建议过度使用太多层级。
- 重要调整后可以点击保存按钮立即写入文件。
